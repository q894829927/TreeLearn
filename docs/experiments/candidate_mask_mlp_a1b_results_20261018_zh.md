## 4. 从本轮能学到什么

1. **当前排序项没有产生预期的整体改善。** 受控变更后 Coverage 上升，但误检代价更大。这既不证明所有相对竞争监督无效，也不支持立即把该项叠加到更复杂模型上。
2. **相对排序不能单独保证绝对分数过阈值。** 当前项只约束两个 logit 的差；例如正确候选 -1、错误候选 -2 的相对排序可以更好，但两者 sigmoid 都低于 0.5。原 BCE/Dice 仍提供绝对监督，最终结果由联合优化决定。未分配量增加与这种局限相容，但不能据此断言它就是本轮退化的已证实原因。
3. **点集 IoU、覆盖率和实例级误检需要同时看。** 4/5 Coverage 提高、全部 Point precision 提高，并不保证 IoU > 0.5 匹配后的 F1 提高；选定的局部验证损失也不等同于完整实例指标。
4. **原 owner 配对并非完整的多候选竞争。** 它跳过同 GT 目标、背景/未知和双方都不正确的点，owner 目标仍来自原冻结映射；它没有显式处理全部竞争者或增加实例质量监督。这是方法边界，不是已经证实的主因。

上述 CPU 操作对照与 FP 转移核算现已完成，量化结果见第 7 节。诊断不改变主判定，其对照是事后分析，不能代替预先定义的新方法。本轮结束追加实验，保留当前权重、缓存和负结果；后续研究边界见第 8 节。

仅丢点的合计 TP 仍为 1633，FP 变为 314；仅改归属的 TP 为 1638，FP 为 337。后者没有未分配点、预测候选数仍为 2595，FP 已从 275 增至 337，说明不能把全部误检增量归于丢点删背景。完整结果 TP 为 1642、FP 为 345。

这些是同一份保存预测的操作干预，存在交互；不能将两个差值相加、将 +62/+70 当作改归属的独立因果贡献比例，或把其中一个事后对照升级为通过原 gate 的新方法。与旧 A1 的相应对照比较，两种操作的 F1 都更差；相对排序监督尚未显示总体收益。

### 7.2 FP 变化完整对账

| 原候选状态 → A1b 状态 | A1 候选数 | A1b 候选数 |
|---|---:|---:|
| excluded_unmatched → counted_fp | 52 | 98 |
| matched → counted_fp | 12 | 12 |
| counted_fp → matched | 18 | 21 |
| counted_fp → excluded_unmatched | 15 | 15 |
| counted_fp → absent | 6 | 4 |
| excluded_unmatched → absent | 164 | 122 |
| matched → absent | 0 | 0 |

A1b 新增 FP 为 98+12=110，移除为 21+15+4=40，净 +70，与主评价 275 → 345 一致。新增计数 FP 中 98/110=89.091% 来自原不计入 FP 的未匹配候选。这些候选修改后树点比例达到计数条件，仍未形成有效匹配；可能涉及删背景、接收树点或两者同时发生，不能仅凭状态表分配原因。

两轮 FP 增量之差 45，在类别计数上对账为：不计 FP → FP 多 46、原 FP 完全消失少 2、原 FP → matched 多 3，即 46+2−3=45；matched → FP 仍为 12。这个结果不支持把“比 A1 多出的 FP”主要归于更多原匹配候选被破坏，也不证明两轮受损的是同一组 ID。

这里的 `excluded_unmatched` 是**评价时的候选状态**：候选未匹配且树点比例不足计数门槛，不等于 `supervision.valid=false` 的**训练筛选状态**。现有摘要没有把两套集合逐 ID 关联，不能据此断言新增 98 个 FP 全部来自被排除的训练候选。

消失的 126 个候选中，122 个原本就不计入 FP，只有 4 个是原计数 FP，没有原已匹配候选完全消失。matched → FP 的 12 个与丢失/恢复 GT 集合的 12/21 属于不同统计对象，数量相符不等于逐 ID 映射相同。计数资格变化是既定评价协议下的实际代价，不是程序错误或忽略它的理由。

## 8. 本阶段收尾与后续研究边界

结束 A1/A1b 当前实现的追加实验，保留两轮负结果和原版 A0 对照。当前单点 MLP 与 owner 排序项在固定候选/监督下均没有满足整体分割条件，简单取消丢点或取消改归属也没有修复；本轮无需再跑命令。按原推进条件，不自动进入 attention、重跑 Wytham、扫描 loss 权重/阈值或追加 epochs。

后续值得另立研究单元的问题是：**以原版分割为可回退基准，如何约束未匹配候选接收树点，同时保留局部纠错能力？** 应将实例有效性、候选间分配与点掩码区分开，预先固定一个变量及其 GT-free 部署规则，再与 A0 比较。不能使用 GT 读取评价状态来屏蔽那 98 个候选，也不能把过去的源域或 Wytham 当作尚未观察的最终测试。

这是当前证据指向的研究问题，不是已实现或已证明有效的新方案。本次只归档诊断与收尾结论，模型、配置、checkpoint 签名和原预测均未修改。
