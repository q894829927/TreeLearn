# 局部实例关系头 V1：诊断结论与下一版方向

## 结论

用户服务器的保存结果诊断已复现原评价，30 个接受动作中有 5 个在单独回放时丢失原正确树，所有动作的 TP/FP/FN 变化之和也与联合执行一致。Wytham 仍是 TP596→591、FP222→215、FN281→286、找回0/丢失5，F1 −0.0928 个百分点。

本轮主要失败位置是关系分类、原实例质量估计和 union 质量 / 增益判断；已知六组碎片未被候选生成漏掉，也未走到互选阶段再被排除。原前景和未选实例保持不变的执行约束有效，但不能替代对接受动作的正确性判断。

原始服务器证据：[received_brief.json](assets/instance_relation_audit_20261022/received_brief.json)；仅对收到数据计算的派生统计：[interpretation.json](assets/instance_relation_audit_20261022/interpretation.json)。本地没有执行模型或重新评价原预测。

| --- | --- | --- |
| 259 | 是 | merge、原实例保护 |

| 419 | 是 | merge、same、union precision / recall / IoU |

六组都符合当前诊断的潜在恢复条件，经过 merge 分数门槛只剩两组，经过 union precision 只剩 629，再经过 union IoU 全部消失。259 另有保护门槛失败。改变互选规则不会让这六组通过此前的门槛；扩大候选半径也不能解决它们已经入图后的误判。

这六组是按现有候选、两两合并和本轮定义得到的 IoU 可行案例，不是保证全部可检出的六棵树，更不是全场 281 棵漏检的可恢复上限。附件未包含完整 watchlist 的逐对分数和单独匹配回放，不能代报这些未提供数值。

## 原实例保护的主要问题已得到区分

12 个被选中的原 TP 都预测在 0.65 保护线下。其中 11 个实际最佳 IoU ≥0.65，只有 1 个实际在 0.5～0.65 之间。因此上一轮提到的“保护阈值没有覆盖 0.5～0.65 TP”只解释一个所选实例的情况；主要问题是质量头把本应达到保护标准的正确实例低估了。

例如原实例 301/302 分别匹配 GT202/777，实际 IoU 为 0.706/0.903，却被预测为 0.411/0.096，合并分数达到 0.995。合并后的最佳单树 IoU 仍有 0.805，但 GT202 丢失。union 最佳 IoU 高并不保证两个原树身份都得以保留。

5 次有害合并全部为不同树标签，实际增益全部为负，预测增益却全部为正；4 次直接合并了两个原 TP。一个增益错号例子是 1107/1108：预测 +0.300，实际 −0.262。

这证明当前质量与收益预测在这些外部案例上不可靠，但没有证明神经特征坍缩，也没有排除输入分布差异、训练样本覆盖、统计特征表达或训练目标各自的作用。

## 学习与选择目标的问题

13 个训练森林共有 8,228 个有效 pair，184 个 merge 正例，占 2.24%；当前训练却按正负 1:1 抽样。这样得到的 sigmoid 分数没有做真实候选分布上的概率校准，不能把 0.995 解释为实际 99.5% 的正确把握。均衡抽样本身不是错误，也不能单独解释高分错对、低分好对的排序问题。

Wytham 的 4,291 个候选中，22 个满足本轮有益合并标签，6 个满足潜在漏检恢复条件；最终接受 30 个动作，仅 1 个满足有益合并标签，比例为 3.33%。其余 29 个不等于全部丢树：真正的单独回放丢树动作是 5 个，其他动作仍可能减少误检而不满足本轮质量增益标签。

merge 正例同时包含已有 TP 的补全和漏检恢复，源域按 F1 选择的策略只表现出误检减少。若继续使用同一分类目标与采样方式，不能指望仅延长训练就自动转向恢复漏检。

## 下一版建议范围

1. 保留已验证的官方冻结缓存、局部候选和只改所选 pair 的 union writer。改动集中于关系判别与接受证据，不更换全场骨干或全场聚类。
2. 给关系头提供接触区域、跨高度邻域和下部支撑的点级信息，并可读取缓存中已有的官方冻结 32D 点特征。现有 54/59 维统计摘要可作辅助，不能将它们等同于已学习到真实树枝或树干连通关系。所有大数组继续 mmap，只取有界局部样本。
3. 优先采样“空间近、投票接近、大小不等但属于不同树”的困难负例，特别是两个完整实例被误判可合并的组合。真实正例之外，只在训练森林构造多种切断 / 遮挡 / 密度变化的同树碎片；混合真实错误对，避免训练只见干净合成碎片。
4. 将恢复漏检与已有 TP 补全分开统计和抽样。准备阶段先统计训练域中两类正例数量，再决定采样比例，不假定现有 184 个正例足够覆盖恢复任务。标注只用于训练标签和评价，不加入部署输入。
5. 监督同树连接与误并风险，验证“两个独立下部支撑或稳定投票峰”的保护证据；这些结构不能无条件当作真树身份，以免误伤多干树或截断树。绝对 IoU / gain 回归先作辅助，不继续叠加多个未经外部验证的硬门槛。
6. 在真实源域验证候选分布上报告恢复类的 precision/recall、误并两个原 TP 的数量和 GT 丢失数，再选接受规则。原候选无编辑作为明确回退项；Wytham 仅事后报告，不按这六个 GT 指定合并动作。

这一方向尚未实现或测出收益。先要求新的判别器能在源域识别恢复类并保住已有树，再做全场外部评估；本轮证据不足以承诺下一版的增益幅度。
