## 关键路径复核结论

- 预测输入保持 xyz/grid/neighbors/core，不加入 GT、TreeLearn 特征或投票。训练标签只用于监督和前期 query 热身。文件预检可读 GT/baseline 的头部，但不读取其值参与预测。
- 浮点监督在数据、张量边界和质量 MSE 目标三处与预测类型对齐。未知体素排除在 mask/质量/语义监督之外，embedding 只监督正实例。
- MFA 的空 hard-mask 分支仍保留原 query，未靠改阈值或删模块让检查通过。None、NaN/Inf 与连接但为零的梯度分开处理；总损失反传另外检查所有可训练参数的连接。
- 验证前先保存训练状态，中断验证后 resume 先补验证；检查与正式训练复用相同的状态恢复函数。检查权重放在 check/，标记 check_only，不作为正式 best/last。
- 主流程继续在终端前台运行并同步写日志；管道保留 pipefail。all/resume 自动执行服务器回归用例。
