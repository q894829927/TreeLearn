日期：2026-10-19。用户回传 Wytham 完整评价、500/500 块处理完成及 `EXIT=0`。与源域使用相同第 2000 step 权重、0.4 原质量阈值和 0.4 分配后校正分数阈值，没有使用 Wytham GT 生成预测。源域规则已由 CPU 实际导出核对通过，F1 89.8309%，`diagnostic_reference_verified=true`。

**v1b 在源域开发集上的 F1 正增益没有延续到 Wytham。** 原版 Wytham F1 70.324%，v1b 为 62.913%，下降 7.411 pp；误检减少，但有效树召回和 GT 覆盖退化。

## 2. 过滤与评价计数

128000 个查询经块内 NMS 留下 11732 个提案，全林 NMS 留下 1756 个；互斥分配得到 1750 个全林实例。分配后规则删除 594 个实例、1304168 个点，留下 1156 个实例和 25395397 个分配点。

评价的 `num_predictions=551` 与全林 `final_instances=1156` 不相等：评价忽略 20131977 个负 GT 点，因此有 605 个最终实例只覆盖忽略区域，不进入有效预测 ID 统计；触及非忽略 GT 点的实例才出现在 551 中。计数 FP 仍要求未匹配预测中标注树点比例至少为 0.5，最终为 97。不能直接用全林实例数减 GT 数计算 FP。

删除的 594 个实例中，哪些含有效 GT 树、哪些只在忽略区域，当前汇总没有给出。删除点数也包含未标注点。**仅凭本份过滤后报告，不能把净丢失的 149 棵树全部归因于分配后过滤。**

Wytham 平均查询质量约 0.460，源域各森林约 0.546–0.628，提示输出分布发生变化；查询群体和点云条件也不同，均值差不能单独证明质量头失准。6 个块发生磁盘暂存，最大单块约 5182 万成员，完整推理约 681.6 秒，未因资源保护中断。

## 3. 下一步只做一项固定权重对照

当前没有保存这次 Wytham 分配后过滤前的完整标签，临时提案成员文件也已释放，无法仅从过滤后的标签或被拒实例的点数恢复未过滤预测。因此使用已有入口重做一次 Wytham 查询预测，关闭**仅分配后的质量乘保留比例规则**；原查询质量阈值 0.4、mask 阈值 0.5、查询、NMS、主干缓存及第 2000 step 权重均保持原样。

不重训、不扫 Wytham 阈值。这个对照用于区分损失主要发生在新增规则之前还是之后：

- 若未加分配后规则时 TP/Completeness 已明显低于原版，需优先检查更早的查询、掩码及原质量筛选环节，不能靠放松分配后阈值解释全部问题。
- 若未加该规则时 TP 接近原版，而过滤后大量下降，则分配后校正的跨域适配是更直接的问题。
- 两类问题可能同时存在。比较 TP、FN、Coverage 与 F1，不能只看单一 F1，也不把新的开发对照当独立测试。
