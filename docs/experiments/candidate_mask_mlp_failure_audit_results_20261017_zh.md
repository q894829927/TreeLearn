# A1 CPU 失败诊断回传与优先级调整

日期：2026-10-17。来源：用户回传 `diagnostics/failure_audit/summary_all.json`。本地只解析 JSON 并核对计数，没有执行点云、模型或单元测试。诊断仍为 `posthoc=true`、`eligible_for_advancement=false`。

## 1. 监督不一致确实存在，但不能仅凭其存在认定主因

| 统计 | 源训练 | 源验证 | Wytham 假设监督 |
|---|---:|---:|---:|
| 有效候选 | 5123 | 1919 | 565 |
| 多候选对应同一 GT 的比例 | 2.739% | 2.471% | 2.000% |
| 可部署唯一正例中被多个候选同时标正 | 2.530% | 1.807% | 0.790% |
| 正例引用中原语义背景占比 | 0.709% | 0.673% | 0.686% |
| 每正候选等权的原语义背景正例比例 | 1.136% | 1.067% | 3.376% |
| 有效标注引用中推理不处理的原背景占比 | 19.576% | 18.988% | 27.431% |
| 按原规则被排除的候选 | 24.750% | 26.050% | 69.656% |

重复 GT 的分母为具有有效候选目标的 GT；唯一点按每个森林去重，汇总时相加。引用数允许一点在多个候选中重复出现，不能混用。Wytham 只用于假设监督的事后诊断，从未加入训练。

因此应下调此前把“共享正例”或“不可部署正例”优先当作主要解释的信心。共享正例和不可部署正例在汇总点量中占比有限，但不能据此排除它们对少量树或小树的影响；不同加权口径的差异也显示影响并不均匀。源域训练/验证中约 19–20% 的有效标注引用位于部署时不评分的原语义背景，主要体现负例支持集差异，作为后续独立变量保留。

源训练被排除的 1685 个候选中，1616 个是充分标注但低 IoU，69 个为其他充分标注困难候选；没有因标注不足被排除的源候选。Wytham 被排除的 1297 个中，1230 个来自标注比例不足。这主要反映标注覆盖差异，不能解释成“Wytham 约 70% 候选都是坏树”，更不能在部署时读取 GT 标签筛候选。

## 2. Wytham 两种操作均有损害

| 相对 A0 的变化（pp） | 完整 A1 | 仅丢点 | 仅改归属、回填未分配点 |
|---|---:|---:|---:|
| F1 | -3.658 | -1.493 | -2.918 |
| Coverage | -3.214 | -1.315 | -1.919 |
| Commission | +3.790 | +1.502 | +3.759 |
| Point recall | -4.670 | -3.539 | -1.110 |

仅改归属已经产生较大的 F1 损失；丢点对点召回的损害更明显。两种操作存在交互，差值不能相加、分摊成独立因果贡献，也不能把其中一个对照改称通过实验的新方法。

丢弃点共 1,056,103 个，其中 GT 树点 146,665、GT 背景点 50,948、忽略点 858,490。**在有标注的被丢弃点中，树点占 74.22%**；忽略点占所有被丢弃点的 81.29%。不能把忽略点视作背景，或把总丢点量直接等同于损坏的树点数量。

改归属点共 1,544,995 个，其中 GT 树点 511,226、背景点 4,828、忽略点 1,028,941。在有标注的改归属点中树点占 99.06%，说明需要研究邻树身份决策；树点改归属不自动等于改错，需要实例身份信息。全部改动点中 72.56% 为忽略点，其正确性不能从当前 GT 判定。

## 3. FP 增加的账目与源域不同

| 转移 | 数量 |
|---|---:|
| matched → counted_fp | 29 |
| matched → absent | 6 |
| counted_fp → matched | 4 |
| excluded_unmatched → counted_fp | 13 |
| no_labeled_points → counted_fp | 23 |
| counted_fp → no_labeled_points | 23 |
| counted_fp → absent | 7 |

新增 FP 65 个，移除 FP 34 个，净增 31，与主报告 222 → 253 一致。未知标注区候选与计数 FP 的双向转移为 23 对 23，在这份 FP 计数账目中净抵消；matched ↔ FP 为 +29−4=+25，其他转移合计净 +6。

原匹配候选 29 个变成 FP、6 个消失，是需要直接保护的已有成功分割。候选状态与 GT 匹配集合是不同对象，虽然本例数量与丢失 35 棵/恢复 4 棵相符，仍不把两套 ID 当成同一映射。结果不支持将全部外部退化归于 FP 计数资格变化，亦不能把源域 52/64 的新增 FP 成因比例套用到 Wytham。

## 4. 下一轮决策

选择单变量 A1b：**保留 BCE/Dice，并增加当前候选与原 owner 在同一点上的相对排序监督**，直接检验独立掩码是否缺少对最终竞争的约束。目标是减少错误抢走原正确树点，同时允许有源域 GT 证据的纠错；不是在推理中强制回填或增加分数门槛。

模型、候选、区域、抽样、归一化、训练轮数、推理阈值/竞争规则和源域 gate 保持相同。方案受已有源域和 Wytham 诊断启发，因此后续 Wytham 不能作为未参与开发的最终测试。具体协议及服务器入口见 [A1b owner 排序实验](candidate_mask_mlp_a1b_owner_rank_20261017_zh.md)。当前诊断没有证明该损失必然修复退化，仍需受控源域实验验证。
