**当前 A1 在 Wytham 上也退化，结束这一版本的追加试验。** 六项指标方向均变差：F1 -3.658 pp，Coverage -3.214 pp，Commission +3.790 pp。结合源域五森林 F1 -0.595 pp 的结果，目前不能支持当前固定候选 MLP 优于原版，也不支持仅用源域基线较高解释其失败。

## 2. 配对指标

协议：`aligned_voxels_ignore_negative_gt_iou_gt_0.5`。A0/A1 在同一份流式切块生成的特征缓存上评分；负 GT 标签忽略，实例匹配严格 IoU > 0.5。

| 指标 | 原版 A0 | A1 | 差值（百分点） |
|---|---:|---:|---:|
| F1 | 70.324% | 66.667% | -3.658 |
| Completeness | 67.959% | 64.424% | -3.535 |
| Commission（越低越好） | 27.139% | 30.929% | +3.790 |
| Coverage | 65.125% | 61.911% | -3.214 |
| Point precision | 71.230% | 68.506% | -2.724 |
| Point recall | 80.367% | 75.697% | -4.670 |

Point precision/recall 沿用当前脚本按每棵 GT 的最高 IoU 预测计算后平均的定义，不是全点 micro 二分类指标。旧 Wytham 历史表格使用过预测到 GT 点云传播等流程，不能把旧约 72% F1 或 57.7% Coverage 与本次结果直接相减；本次应比较表内 A0/A1。

| 实例计数 | A0 | A1 | 变化 |
|---|---:|---:|---:|
| GT 树数 | 877 | 877 | 0 |
| TP | 596 | 565 | -31 |
| FP | 222 | 253 | +31 |
| FN | 281 | 312 | +31 |
| 有效标注点上出现的预测 ID 数 | 860 | 839 | -21 |

丢失原已匹配 GT 35 棵、恢复原未匹配 GT 4 棵，净少匹配 31 棵，与 TP 差值完全一致。匹配 ID 集合差已在本地仅用回传 JSON 核对，无需重新推理。

`num_predictions` 统计过滤负 GT 后仍出现的预测 ID；`assignment.num_*_instances` 统计所有点上的实例 ID，两者不同不表示计数错误。FP 也不等于所有未匹配 ID：评价仅计入未匹配且至少一半有效标注点属于 GT 树的预测。不能从“实例少了 51 个”推出误检减少；本次 FP 实际增加 31 个。没有外部逐候选状态转移，不能把源域诊断中的 FP 成因比例套用到 Wytham。

## 3. 运行和分配诊断

- 阈值固定 0.5；全部 1862 个候选参与评分。
- 29,031,598 个原前景点全部被评分，未评分点为 0，`empty_prediction_reason=null`。
- 候选—点评分对 320,257,349 个，其中 38,317,363 个达到阈值；最高概率 0.9999764。该数量包含每个点对多个候选的评分，平均概率和过阈值比例不能单独作为校准好坏的证据。
- 1,816 个候选至少有一个过阈值分数，竞争后保留 1,811 个实例；最终消失 51 个原候选。
- 原前景点中 1,056,103 个未分配，占 3.638%；总改动点 2,601,098 个，占原前景的 8.960%。其中 1,544,995 个为保留前景的跨候选改归属，其余为未分配。
- MLP 推理耗时 39.793 秒，所记录 CUDA 峰值 36,210,176 bytes，约 34.533 MiB。这是该 MLP 推理区间的记录，不是完整主干推理/聚类的显存或全流程资源峰值。

这次存在正常非空预测、全部前景均被评分，因此没有重现 smoke 的全分数低于阈值或前景未评分问题。最终报告说明流式切块、主干特征缓存和外部评价链路已走通；此前切块 OOM 的工程修复不等于模型效果改善。新 34 项单测的最终日志及整轮 prepare 的最大内存尚未单独回传，不把它们记为已验证数值。
